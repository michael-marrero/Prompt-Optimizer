<objective>
Implement the computer-use adapter — async browse-and-act backend using `anthropic 0.40+` `client.beta.messages.stream(...)` with the `computer_20251124` tool + `computer-use-2025-11-24` beta header, owning a full agent loop (screenshot → model → action → screenshot) and driving a headless Playwright Chromium sandbox. It is the heaviest of the three adapters (full agent loop, Playwright lifecycle, per-iteration screenshot encoding). The opt-in flag prevents accidental spend; the Playwright sandbox bounds blast radius to a browser tab.
