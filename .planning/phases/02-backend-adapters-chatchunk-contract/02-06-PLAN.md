<objective>
Close gap CR-02: `ComputerUseCostTracker.record_iteration_usage` is documented as "Override the running estimate with provider-reported usage" but the implementation uses `+=` instead of `=`, so per-iteration `record_output_text` char/4 estimates are summed with the authoritative Anthropic usage block. This inflates `Done.tokens_out` AND the `over_cap()` arithmetic that drives `cost_cap_exceeded` decisions, causing the per-turn cost cap (BACKEND-06 / ROADMAP SC #2) to fire too early relative to the operator-set $0.50 budget.

Purpose: BACKEND-06 / ROADMAP SC #2 require correct cap arithmetic. SECURE-04 adjacency — the cap is the denial-of-service control that prevents a runaway computer-use agent from billing through an operator's budget. The parallel `OpenRouterCostTracker.record_final_usage` and `ClaudeCodeCostTracker` (per `_final_cost_override`) both correctly use override semantics; only `ComputerUseCostTracker` is wrong.

```python
def record_output_text(self, text: str) -> None:
    if not text:
        return
    self.record_output(len(text) // _CHARS_PER_TOKEN)  # adds char/4 to _tokens_out

def record_iteration_usage(
    self, *, input_tokens, output_tokens, cache_read=0, cache_write=0,

    self._tokens_in += int(input_tokens)        # <-- BUG: should be `=`
```

```python
def record_result(self, msg) -> None:
    """Authoritative ResultMessage.total_cost_usd overrides running estimate."""
    cost = getattr(msg, "total_cost_usd", None)
    if cost is not None:
        self._final_cost_override = float(cost)
    # usage replacement also uses =:
    usage = getattr(msg, "usage", None)
    if usage is not None:
        self._tokens_in = int(getattr(usage, "input_tokens", self._tokens_in) or 0)
        self._tokens_out = int(getattr(usage, "output_tokens", self._tokens_out) or 0)
```

## Trust Boundaries

| Boundary | Description |

| operator → cost cap | Operator sets `max_cost_usd` (default $0.50 per turn) as a denial-of-service control. If the cap arithmetic is wrong, the runaway-agent protection misfires (either too early — false-alarm; or too late if estimator under-counts — true alarm). |

The fix changes two `+=` to `=` and adds a unit test that uses the exact reproduction from VERIFICATION.md (text="x"*40 + record_iteration_usage(10, 5) → expect (10, 5), not (10, 15)). ASVS V8 (data protection / business logic correctness) — the cap is a budget control. |
| T-02-CR02-02 | T (Tampering — n/a) | n/a | accept | No untrusted input mutated; the bug is pure arithmetic. |
| T-02-CR02-03 | I (Information disclosure via inflated Done.tokens_out) | terminal `Done` chunk | mitigate | `Done.tokens_out` is the audit signal for cost-reporting downstream.
