`@router.post("/threads/{thread_id}/rename")` → `async def rename_thread(thread_id: str, body: RenameRequest, request: Request) -> dict`:
- Pre-flight: confirm thread exists.
  - `db = request.app.state.db`.
  - `thread = await get_thread(db, thread_id)`.
  - If `thread is None`: `raise HTTPException(status_code=404, detail="thread not found")`.
- Pre-flight: tiktoken token cap (defense against cost-overrun).
  - `estimated = len(_ENC.encode(body.first_user_message))`.
  - If `estimated > RENAME_MAX_INPUT_TOKENS`: `raise HTTPException(status_code=413, detail=f"first_user_message too long ({estimated} tokens > {RENAME_MAX_INPUT_TOKENS})")`.
- Pre-flight: OpenRouter key presence check (so a missing key produces a clean 400, not a typed `openai.AuthenticationError` 500 from the adapter constructor):
  - `key = request.app.state.keystore.get("openrouter")`.
  - If `not key`: `raise HTTPException(status_code=400, detail="OPENROUTER_API_KEY not set; rename requires an OpenRouter key (set it via PATCH /api/v1/settings or the OPENROUTER_API_KEY env var)")`.
- Build a FRESH OpenRouterAdapter (NOT the cached one per D-17):
  - `adapter = OpenRouterAdapter(api_key=key, max_cost_usd=RENAME_MAX_COST_USD)`  # `key` from the pre-check above is guaranteed non-empty here.
- Stream the one-shot:
  - `title_parts: list[str] = []`.
  - `async for chunk in adapter.stream(prompt=body.first_user_message, history=[AdapterMessage(role="system", content=RENAME_PROMPT_TEMPLATE)], options=AdapterOptions(model=RENAME_MODEL, max_cost_usd=RENAME_MAX_COST_USD, max_steps=1)):`
    - `if chunk.type == "text_delta": title_parts.append(chunk.text)`.
    - `elif chunk.type == "done": break`.
- Trim + persist:
  - `title = "".join(title_parts).strip().strip('"').strip("'")[:60]`.
  - `await update_thread_title(db, thread_id, title)`.
- Return `{"title": title}`.

NEVER call `decide()` — rename is the bypass route per UI-14 explicit (D-17).
NEVER use the cached adapter from `app.state.adapters["openrouter"]` — D-17 requires a fresh per-request instance (defensive: the cached one might have a stale key after a missed cache-clear; rename's <$0.01 budget is small enough that the per-request cost of constructing a new adapter is negligible).
