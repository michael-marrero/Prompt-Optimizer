Helper functions:

`def _mask_key(key: str) -> str:`:
- If `len(key) <= 6`: return `"…" + key[-3:]` (very short keys still get truncated).
- Else: return `key[:6] + "…" + key[-3:]` (e.g., `"sk-or-v1-XYZABC..."` → `"sk-or-…ABC"`).

`def _mask_settings_for_response(settings: dict, keystore) -> dict:`:
- For each provider in `("openrouter", "anthropic")`:
  - `key = keystore.get(provider)`.
  - `present = key is not None`.
  - `masked = _mask_key(key) if present else None`.
- Return:
```
{
    "keys": {
        "openrouter": {"present": ..., "masked": ...},
        "anthropic": {"present": ..., "masked": ...},
    },
    "backends_enabled": settings.get("backends_enabled", _default_settings()["backends_enabled"]),
    "computer_use_opt_in": settings.get("computer_use_opt_in", False),
    "default_max_cost_usd": settings.get("default_max_cost_usd", 0.50),
}
```

`def _merge_patch(current: dict, patch: dict) -> dict:` — RFC 7396-ish shallow merge for non-key fields; `keys` deletions handled separately in the PATCH handler.
