`async def _current_version(db) -> int`:
- Try `SELECT version FROM schema_meta LIMIT 1`; return `int(row[0])` if found, else 0 (rare edge: schema_meta table exists but is empty).
- On `aiosqlite.OperationalError` (table missing — fresh DB), return `-1`.

`def _discover_migrations() -> list[tuple[int, Path]]`:
- Glob `MIGRATIONS_DIR.glob("schema_v*.sql")`, parse the integer from `path.stem.removeprefix("schema_v")`, sort by integer.
- Skip files that don't parse cleanly (`ValueError` → continue).

`async def up_to_latest(db: aiosqlite.Connection) -> None`:
- Read `current = await _current_version(db)`.
- For each `(version, path)` in `_discover_migrations()`:
  - If `version <= current`: continue (already applied).
  - `sql = path.read_text(encoding="utf-8")`.
  - `await db.execute("BEGIN")` — explicit BEGIN.
  - try: `await db.executescript(sql)`; if `current < 0`: `await db.execute("INSERT INTO schema_meta (version) VALUES (?)", (version,))`; else: `await db.execute("UPDATE schema_meta SET version = ?", (version,))`; `await db.commit()`.
  - except Exception: `await db.rollback()`; raise.
  - `current = version`.
- Log INFO at each migration applied: `logger.info("Applied schema_v%d.sql", version)`.
