ReadMe.md will gain a "DO NOT load joblib files from untrusted sources" advisory in Phase 6 (OSS-04). Inside Phase 1, the threat is documented here so the planner of Phase 2 / 3 inherits awareness; no code change in Wave 0 beyond surfacing this entry. |
