Canary CSV schema (D-13 + D-14 + D-15 + RESEARCH §Pattern 5 lines 632-668):

  Columns (header row exactly):
    prompt,expected_backend,expected_model_or_agent_substring,is_fallback_expected,edge_case_category,source,license

  Column semantics:
    - prompt (str): the text fed to decide()
    - expected_backend (str): one of {openrouter, claude_code, computer_use}. For fallback rows: openrouter (not "fallback").
    - expected_model_or_agent_substring (str): substring expected in decide() result. For fallback rows: "openrouter/auto". For claude_code: "claude-agent-sdk". For computer_use: "computer-use-2025-11-24". For openrouter normal: a verifiable substring of any of the 16 mapped api_models (e.g., "gpt-5" or "gemini" or "openrouter/auto").
    - is_fallback_expected (bool): TRUE for the ~6 low-confidence-trap rows.
    - edge_case_category (str): one of {haiku-vs-code, explain-vs-build, informational-url, low-confidence-trap, golden-path, ""}
    - source (str): one of {hand-written, humaneval, mmlu, webarena, paraphrase-of-X}
    - license (str): one of {mit, apache-2.0, cc-by-sa, paraphrase-of-X}

  Distribution target (D-13):
    ~12 openrouter (normal chat / coding-via-chat-model)
    ~12 claude_code (build/edit prompts)
    ~12 computer_use (browse/click prompts)
    ~6 fallback (gibberish, emoji-only, single-token, multi-language ambiguous)

  Edge-case guaranteed slots (D-15, >=8 of the ~42 rows):
    Haiku-vs-code (2 rows):
      "write a haiku about recursion" -> openrouter (chat, creative)
      "write a Python function for fizzbuzz" -> openrouter (chat coding model, NOT claude_code)

    Explain-vs-build (2 rows):
      "explain how OAuth works" -> openrouter (chat)
      "build me a login flow with OAuth" -> claude_code (imperative + agentic)

    Informational-URL (2 rows):
      "summarize https://example.com/article" -> openrouter (URL present but action is summarization)
      "open https://example.com and click subscribe" -> computer_use (URL + action verb)

    Low-confidence trap (2+ rows):
      "🌶️🌶️🌶️" -> fallback (emoji-only)
      "asdfgh" -> fallback (gibberish)
      "yes" -> fallback (single token)
