1. predict_task_type(...) -> (label, conf, table)
2. predict_best_model(...) -> (label, conf, table)
3. choose_final_route(label, model_mapping) -> dict
4. Returns a dict the existing print_route_result(:359-414) consumes.

After Plan 06, the equivalent flow is delegated to decide(). The wrapper sketch (RESEARCH §Pattern 7 lines 706-731):

    from src.routing.decide import decide
    from src.routing.schema import RoutingDecision

    def route_prompt(prompt, task_artifacts, model_router_artifacts, model_mapping, extractor):
        agentic_artifacts = load_joblib_artifacts(
            os.path.join(MODELS_DIR, "agentic_intent_classifier.joblib"),
            "agentic_intent_classifier.joblib",
        )
        decision: RoutingDecision = decide(
            prompt=prompt,
            artifacts={
                "task_type_classifier": task_artifacts,
                "model_router": model_router_artifacts,
                "agentic_intent_classifier": agentic_artifacts,
                "model_mapping": model_mapping,
            },
        )
        # Adapt RoutingDecision back to the legacy dict shape print_route_result expects.
        return _decision_to_legacy_dict(decision, model_mapping)
